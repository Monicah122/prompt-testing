# prompt-testing
Testing how different prompt styles affect AI responses and output quality.# Prompt Testing Project

## Overview
This project explores how different prompt styles affect the quality of AI-generated responses.

## Objective
To understand how prompt structure, clarity, and wording influence AI output quality.

## Methodology
- Created multiple versions of prompts for the same task
- Generated responses using AI tools
- Compared outputs based on:
  - Clarity
  - Accuracy
  - Structure
  - Usefulness

## Findings
- Clear and specific prompts produce better results
- Vague prompts lead to inconsistent or incomplete answers
- Small wording changes can significantly affect output quality

## Skills Demonstrated
- Prompt design and structuring
- Analytical thinking
- Attention to detail
- AI evaluation
